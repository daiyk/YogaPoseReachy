Reachy Mini App

Reachy Mini Pose Coach

A voice-driven yoga and pose coach for Reachy Mini Lite and Wireless.

Getting Started

Installation

This is a private app for approved eth-sbs members. Authenticate your Reachy setup with your authorized Hugging Face account, then install the private Space eth-sbs/reachy_mini_pose_coach. See the repository README for the official installation API.

For updates, stop Pose Coach and use Reachy Mini's app manager to fetch the latest version from the same Space. No custom updater or AI agent is needed.

Configuration

Speech server

The app uses a hosted Hugging Face realtime speech server by default. You can choose your own compatible server in the app’s Speech server settings. Pose tracking runs locally on your computer or robot.
